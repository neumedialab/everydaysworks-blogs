# Sonraki geliştirme: yorum ve reaksiyon sistemi

Bu özellik şimdilik ertelendi; mevcut yayında yalnızca ücretsiz statik sosyal paylaşım düğmeleri kullanılacak.

## Değerlendirilecek seçenekler

1. **Giscus / GitHub Discussions:** Ücretsiz ve hızlı başlangıç. Okuyucular GitHub hesabıyla yorum ve reaksiyon bırakır. Repository Discussions özelliğinin açılması ve Giscus uygulamasının yetkilendirilmesi gerekir.
2. **Everydaysworks’e ait yorum sistemi:** Kullanıcıların takma adla yorum yapması, like/dislike, spam bildirimi ve moderasyon kuyruğu. Cloudflare Workers/R2 veya uygun bir veritabanı, gizlilik metni ve yönetim arayüzü gerektirir.

## Daha sonra netleştirilecek kararlar

- Okuyucuların GitHub hesabı kullanması kabul edilebilir mi?
- Yorumlar yayınlanmadan önce moderasyon gerekecek mi?
- Like/dislike anonim mi, oturum açmış kullanıcıya mı bağlı olacak?
- Silme, bildirme ve gizlilik süreçleri nasıl işleyecek?

Bu not, sıcak haber yayın akışını yavaşlatmamak için yalnızca planlama amacıyla tutulmaktadır.
